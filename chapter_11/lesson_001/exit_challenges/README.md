# Lesson 1 Exit Challenge Solutions

These folders are one way to complete the three Exit Challenges in Chapter 11, Lesson 1. Try each challenge yourself first. When you're ready, compare your work with the files here.

Copy a solution's files into the matching places in your `project_2` folder, keeping the same folder names (`journal/`, `journal/templates/journal/`, `static/css/`).

| Challenge | Folder |
|---|---|
| Backend: Answered Prayers | [backend_answered_prayers](backend_answered_prayers/) |
| Frontend: Your Own Style | [frontend_your_own_style](frontend_your_own_style/) |
| Database: Topic Statistics | [database_topic_statistics](database_topic_statistics/) |

Each challenge is independent and starts from the [end of Lesson 1](../end_of_lesson/) project. You can complete one, or all three.
