# Django Prayer Journal Project

## Software

- Python 3.12 or newer
- Django 6.1.3 (`pip install django==6.1.3`)

## Goals and Functionality

- A home page greets visitors and explains the site.
- Users can register, log in, and log out (the Log in button becomes Log out).
- Each user's topics and entries are private.
- Users can create and delete prayer topics.
- Each topic has its own page of prayer entries.
- Users can create, edit, and delete entries.
- Each entry records the date it was created or edited.

## Appearance and Style

- The site has a clean, consistent look on every page and works well on phones, tablets, and computers.
