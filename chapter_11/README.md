# Chapter 11

Downloadable files for Chapter 11 of *Python with a Worldview - 2nd Edition*.

To download a single file, click it, then click the **Download raw file** button (the down-arrow icon) at the top right of the file view.

If PowerShell says running scripts is disabled when you activate a virtual environment, follow the [Windows guide for enabling PowerShell scripts](../setup/windows_enable_scripts.md).

To create a Python virtual environment on Windows 11, macOS, or Linux, follow the [virtual environment setup guide](../setup/virtual_environments.md).
