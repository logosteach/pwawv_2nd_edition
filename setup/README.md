# Setup guides

Short setup instructions for *Python with a Worldview - 2nd Edition*. The textbook links here so the same steps are not repeated in every lesson.

- [Set Up a Python Virtual Environment](virtual_environments.md) — create and activate a `.venv` folder on Windows 11, macOS, or Linux.
- [Enable PowerShell Scripts on Windows 11](windows_enable_scripts.md) — use this if PowerShell says running scripts is disabled when you activate a virtual environment. Students on macOS and Linux can skip this page.
