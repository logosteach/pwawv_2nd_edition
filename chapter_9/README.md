## How to download

- **One file:** open the file, then click the **Download raw file** button (the down-arrow icon) at the top right.
- **Everything:** go to the main page of this repository, click the green **Code** button, then **Download ZIP**.

Keep each lesson's files together in one folder on your computer so the imports in the test files work.
