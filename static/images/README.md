# Course images

Simple, generic icons used in *Python with a Worldview, 2nd Edition* and its online course. Students are welcome to use them in their own projects.

## How to link an image

GitHub's raw file URL (`raw.githubusercontent.com`) serves SVG files as plain text, so they will not display in an `<img>` tag. Use jsDelivr instead:

```html
<img
  src="https://cdn.jsdelivr.net/gh/logosteach/pwawv_2nd_edition@main/static/images/icons/anchor-generic.svg"
  alt="Anchor"
  width="50"
  height="50">
```

The general pattern is:

```text
https://cdn.jsdelivr.net/gh/logosteach/pwawv_2nd_edition@main/static/images/<path>
```

Replace `<path>` with the file path below, for example `emoji/rocket.svg` or `emoji/steps/step-1.svg`.

jsDelivr caches the `@main` branch for up to about 12 hours, so a change pushed to this folder may take a little while to show up.

## Folders

- `icons/` — section badges and the generic course anchor
- `emoji/` — small icons used in the lessons (faces, devices, actions, arrows, and editor buttons)
- `emoji/steps/` — numbered step badges for lab instructions (1–50)

## Custom textbook badges

These two icons were drawn as badges for specific textbook sections. They live here with the other course icons:

- `icons/bible.svg` (also used as a section badge)
- `icons/coding-in-history.svg` (also at `emoji/coding-in-history.svg`)
